# Pratham Vidhani — Software Engineer Portfolio

An art-directed, Swiss editorial personal portfolio website built with **React 19**, **Vite 6**, and **Vanilla CSS Design Tokens**.

Designed to showcase backend engineering rigor, reactive microservices, local-first RAG pipelines, and verified research.

---

## 🎨 Visual System & Identity

- **Aesthetic**: Swiss International Typographic Studio
- **Palette**: Warm Cream Canvas (`#F7F4EE`), Deep Ink Typography (`#111113`), and Restrained Electric Cobalt Accent (`#1D4ED8`)
- **Grid**: 12-column Swiss grid layout with crisp 1px hairlines (`#D8D2C5`) and high deliberate whitespace
- **Typography**: `Space Grotesk` (Headings), `Inter` (Body), `JetBrains Mono` (Code & Telemetry)

---

## 🚀 Key Features

- ⚡ **Hero & Spec Metrics**: Asymmetric typographic statement, framed architect photo, and spec telemetry strip.
- 📦 **Interactive Engineering Case Studies**: 5 production case studies with slide-over drawer modals and custom architecture topology diagrams:
  - **Reactive API Gateway** (Spring Cloud Gateway, Netty, Redis 20 req/s rate limiter, Resilience4J)
  - **Document Intelligence RAG API** (FastAPI, LangChain, pgvector, Ollama Llama 3.1 & nomic-embed-text local execution, Redis vector cache)

  - **Interview AI Web App** (React 19, Express 5, Gemini API, Zod schema validation, Puppeteer PDF)
  - **AI Code Reviewer Engine** (React, Express, Gemini 2.0 Flash, Prism.js)
- 💼 **Work Experience Ledger**: Technical history covering C++/Qt6 desktop engines at Tektutor and production AI pipeline engineering at Amari AI.
- 📄 **IEEE Publication & Problem Solving**: Dedicated paper card for crop water estimation research (LSTM, Penman-Monteith, GA) and DSA problem-solving in C++.
- 🛡️ **Verified Credentials**: Certified Ethical Hacker (CEH), NPTEL Wildlife Ecology (Elite — 97%), IBM QRadar AI, Data Analytics.

## ⚙️ Getting Started Locally

### Prerequisites

- Node.js (v18+ recommended)
- npm or yarn

### Installation & Development

```bash
# 1. Clone the repository
git clone https://github.com/PrathamV239/Portfolio.git
cd Portfolio

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev
```

Open **`http://localhost:3000`** in your browser.

---

## 📦 Production Build

```bash
# Generate production bundle in dist/
npm run build

# Preview production build locally
npm run preview
```
